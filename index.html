基本操作説明

このツールは、ゲーム内に表示される累積の勝数・敗数を週初と確認時点の2回入力し、その差分から今週の戦況を計算します。

0. 最初に一度だけ設定する

設定 → 自ウィッカ で自分の所属ウィッカを選び、保存します。

設定 → 累積領土pの初期値 に、ツールを使い始める時点の東・西・南・北それぞれの現在の累積領土pを入力します。週間増減ではなく、ゲーム上の現在値です。

確定済み履歴がまだ無い場合だけ、お茶会の直近実績も設定します。不明なら「不明」のままで構いません。

1. 月曜0:00 ― 週を作り、開始値を入れる

記録 → ＋ 新しい週を作成 で、その週の月曜日、満月対象、週タイプを登録します。

ゲーム内で東・西・南・北の累積勝数・累積敗数を月曜0:00に取得します。

記録 → ① 週初（月曜0:00）の入力 に4ウィッカ分を貼り付け、「解析する」→内容を確認して保存します。

例：月曜0:00に「南 92,850勝 / 23,120敗」と表示されていたら、その92,850 と 23,120を週初値として使います。「今週だけの勝敗数」を自分で計算して入れる必要はありません。

2. 戦況を見たい時 ― 現在値を入れる

戦況を確認したい時点で、もう一度ゲーム内の4ウィッカの累積勝数・累積敗数を取得します。

記録 → ② 報告時点（現在）の入力 にその数字を貼り付け、「解析する」→保存します。

ツールが 報告時点 − 月曜0:00 を計算し、その週の勝数・敗数を出します。戦況 タブで予測BP、満月込み推定順位などを確認できます。

週の途中で再確認したい場合は、同じ「② 報告時点」に最新値を入力します。

3. 次の月曜0:00 ― 今週を締める

次の月曜0:00になったら、再び4ウィッカの累積勝数・累積敗数を取得し、今週の ② 報告時点（現在） に入力します。

この月曜0:00の数字が、今週の締め値です。同時に次週の開始値でもあります。通常週なら「この報告データを次週の週初として引き継ぐ」で再入力を省けます。

領土戦停止週の後は引き継がず、再開週の月曜0:00に改めて新しい数字を取得します。

4. 最終順位が出たら確定する

戦況 → 実際の最終結果 で、ゲーム内で確定した東・西・南・北の最終順位1〜4位を入力します。

お茶会の実績が分かる場合は「開催／不開催」を選び、記録が無ければ「不明」のままにします。

「この週の結果を確定する」を押すと、順位に応じた領土p増減（1位+3 / 2位+1 / 3位0 / 4位-2）が記録され、履歴と次週以降の判断に使われます。誤って確定した場合は、同じ欄の「未確定に戻す」で確定結果だけを取り消せます。

5. 方針を考えたい時

レポート で戦況テンプレートと目標順位を確認できます。ChatGPT連携 では、現在週の分析用テキスト、または確定済み過去週の振り返り用テキストをコピーできます。

6. 現在の戦況を他の人へ渡す

画面上部の 戦況を共有する で、掲示板へ貼れる TWTSH1: 形式の共有コードを作れます。

共有コードには、同じ戦況計算とAI相談を再現するために必要な現在値・確定履歴・領土p・お茶会情報・目標設定などを含めます。一方、訂正履歴や使われなくなった古い入力は省いて短くします。

受け取った側は画面上部の 共有戦況を受け取る に貼り付けます。読み込みはその端末の戦況データを置き換えます。

端末移行や完全な保管には、設定 → データのバックアップ → 完全バックアップを保存 を使ってください。

数字を入れる場所の要点：
月曜0:00の累積勝敗 → 「① 週初」
戦況を見たい時点の累積勝敗 → 「② 報告時点」
次の月曜0:00の累積勝敗 → まず今週の「② 報告時点」
確定した1〜4位 → 「戦況」タブの「実際の最終結果」
